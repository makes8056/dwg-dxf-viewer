# DWG・DXFビューア

CADの図面（DXF／DWG）を、iPadやパソコンのブラウザで開いて見るためのアプリです。
管工事の現場・出先で、図面を確認して**必要な部分だけを印刷する**ことを目的にしています。

## できること（作っている途中です）

| | 内容 | 状態 |
| :-- | :-- | :-- |
| 1 | 図面（DXF）を開いて見る。スワイプで移動、ピンチで拡大縮小 | 作成中 |
| 2 | **範囲を枠で囲んで、その部分だけ印刷する**（このアプリの一番の目的） | これから |
| 3 | 2点をタップして寸法を測る。図面に文字を書き足す | これから |
| 4 | DWGをそのまま開く | これから |
| 5 | ホーム画面に追加してオフラインで使う | これから |

## 図面ファイルは外に出ません

**このアプリはサーバーを使いません。**
図面を読むのも、描くのも、印刷用に加工するのも、すべてお使いの端末（iPad）の中だけで行います。
図面ファイルがインターネットのどこかへ送られることはありません。

## アプリを開く

**https://makes8056.github.io/dwg-dxf-viewer/**

## 使い方（iPad）

1. Safariで上のページを開く
2. 「図面を開く」を押して、ファイルアプリやiCloudから図面を選ぶ
3. 指1本でなぞると移動、指2本でつまむと拡大縮小

**電波の無い現場でも使いたい場合は、必ずSafariで開いてください。**
Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アイコンから起動できるようになり、
電波が無くても開けます。

iPadのChromeでは、この「ホーム画面に追加」が使えない決まりになっています
（iPadのChromeは、中身がSafariと同じ仕組みで動いているためです）。
Chromeでも図面を見ること自体はできますが、そのつど電波が必要です。

## 作り方

- 素のJavaScript（ES2022）＋ESモジュール。**ビルドは使いません。**
  npm・React・Vite・TypeScriptは使いません。ファイルをそのまま置けば動きます。
- 描画は HTML5 Canvas の2D。
- 外部の部品は `vendor/` にファイルとして同梱します（外部サーバーから読み込みません）。

詳しくは `開発ルール.md` を見てください。

## 使用許諾（ライセンス）

このアプリは **GPL-3.0** で公開しています（`LICENSE` を見てください）。

DWG形式を読むために `libredwg-web`（LibreDWGをWebAssembly化したもの）を同梱しており、
これがGPL-3.0であるためです。

公開されるのは**アプリのプログラムだけ**です。お客様の図面は公開されません。
